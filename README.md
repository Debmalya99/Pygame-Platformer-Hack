# Pygame Platformer: Hackstar
Well, its not called Hackstar of course. That's just temporary name for now. But one fine afternoon I had the itch to read someone else's code and just hack away. 

Usually when its time to create a game, I create it using Godot or a similar Engine, the heavy boilerplate thta you need for creating one in Pygame discourages me to some extent. But this time I thought, hey, why not give it a try. I mean, how bad can it be? So here you
have it "Hackstar" the game.

At least now I am not building an engine which to me is a great win.

## Navigating Around the Project: The Files
- Hackstar has a very simple structure. Most of the game is in the *Game* class which is in main.py. I could have moved it to its own fil; decided not to do so, until things get more complex.
- Else there is the engine file which is just a bunch of classes that are used across the game.
- "sprites" contain the graphics and "sounds" contain the sounds for the game.


## Dependencies

Have Python installed then install the following
```
$ pip install pygame
```

## Deployment
simply run the following
`python main.py`
